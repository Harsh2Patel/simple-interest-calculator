Simple Interest Calculator

Overview
This project is a simple interest calculator that computes the interest earned or owed on a principal amount over a specific period of time at a given annual interest rate.

Formula
Simple Interest = (Principal * Rate * Time) / 100

Parameters
- Principal (P): The initial amount of money invested or borrowed.
- Rate (R): The annual interest rate (in percentage).
- Time (T): The time period in years.

Example
If Principal = 1000, Rate = 5%, and Time = 2 years:
Simple Interest = (1000 * 5 * 2) / 100 = 100
Total Amount = 1000 + 100 = 1100

How to Use
1. Clone or download this repository.
2. Run the simple interest calculator script.
3. Enter the principal amount, annual interest rate, and time in years when prompted to view the calculated simple interest.
